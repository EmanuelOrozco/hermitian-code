\begin{abstract}
Implementación numérica del método de Raman y Fan para calcular estructuras
de bandas en cristales fotónicos con materiales dispersivos tipo Drude.
El problema se formula como $\omega A x = B x$, con $A$ definida positiva y
$B$ Hermitiana en el caso sin pérdidas. La transformación
$\hat{H}=A^{-1/2}BA^{-1/2}$ permite resolver un problema estándar de
autovalores Hermitiano.
\end{abstract}

\section{Referencia}

El trabajo implementado se basa en Raman y Fan~\cite{Raman2010}, donde se
introducen campos auxiliares para convertir el problema dispersivo en un
problema de autovalores lineal.

\section{Modelo Drude}

Para reproducir las figuras principales se usa el caso Drude:
\begin{equation}
  \omega_0 = 0, \qquad \omega_p = 1, \qquad \varepsilon_\infty = 1.
\end{equation}

La permitividad es:
\begin{equation}
  \varepsilon(\omega) =
  \varepsilon_\infty
  \left(
    1 + \frac{\omega_p^2}{\omega_0^2 - \omega^2 + i\gamma\omega}
  \right).
\end{equation}

\section{Problema Hermitiano}

En el caso sin pérdidas:
\begin{equation}
  \omega A x = Bx.
\end{equation}

Como $A$ es definida positiva, se define:
\begin{equation}
  y = A^{1/2}x,
\end{equation}
y se obtiene:
\begin{equation}
  \omega y = A^{-1/2}BA^{-1/2}y.
\end{equation}

\section{Caso numérico}

Para la reproducción de la figura de bandas se usan:

\begin{itemize}
  \item barras cuadradas metálicas en aire;
  \item lado del cuadrado $s = 0.25a$;
  \item resolución $20\times20$;
  \item ruta $\Gamma \rightarrow X$;
  \item polarización TE.
\end{itemize}

Para la comparación de pérdidas se usa:
\begin{equation}
  \gamma = 0.01\omega_p.
\end{equation}
